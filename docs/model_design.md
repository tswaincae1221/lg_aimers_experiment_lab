# 1차 모델: 상황 + 과거 제구력 + 최근 관측 상태

## 예측식

1차 모델은 한 투구의 제구 성공 확률을 다음 세 정보의 비선형 결합으로 본다.

\[
P(\text{control success})
= f(\text{현재 상황},\ \text{과거 제구력},\ \text{최근 관측 상태})
\]

상호작용은 별도 정보 영역으로 분리하지 않고 LightGBM이 학습하게 한다. 볼넷 회피,
병살 유도 같은 투구 의도는 데이터에 직접 관측되지 않으므로 1차 모델에 규칙으로 넣지 않는다.

## 피처 구성

| 영역 | 구현 내용 |
|---|---|
| 현재 상황 | 볼·스트라이크, 아웃, 이닝, 점수 차, 주자, LI, 손잡이, 팀·선수 ID |
| 과거 제구력 | 투수 전체·직전 시즌·최근 20/50/100구 평활 성공률 |
| 상황별 제구력 | 투수×볼카운트, 주자 유무, 득점권, 타자 손잡이 성공률 |
| 최근 관측 상태 | 공식 `asof_` 최근 경기 피처, 이전 시즌 Trackman 평균·표준편차·변화량 |
| 신뢰도 | 제구/Trackman 표본 수, 신규 투수, ID 매칭 신뢰도와 결측 플래그 |

상황별 성공률은 상황 전체 평균을 사전분포로 사용해 평활화한다.

\[
\hat p = \frac{s + m\mu}{n+m}
\]

기본 평활 강도는 `m=50`이며 실험으로 조정한다.

## 누수 방지

- 시즌 \(s\)의 자체 집계 피처는 `season < s`인 학습 행만 사용한다.
- 시즌 \(s\)의 Trackman 피처도 `season < s`인 로그만 사용한다.
- 테스트 행끼리 정렬·집계하거나 테스트의 숨은 결과를 추론하지 않는다.
- 팀 공통 시간순 검증은 2019~2023 시즌으로 학습하고 2024 시즌만 검증한다.
- 투수↔Trackman 매칭은 `확정`, `높음` 등급만 사용하고 나머지는 결측 처리한다.

## 평가 기준

공식 평가지표가 Brier Skill Score이므로 학습 조기 종료와 모델 비교의 기본 손실을 Brier
Score로 둔다. 확률 평균과 실제 성공률 차이도 함께 기록해 보정 상태를 확인한다.
