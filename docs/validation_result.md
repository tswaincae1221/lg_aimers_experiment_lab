# 1차 모델 실제 데이터 검증 결과

## 검증 설정

- 학습: 2019~2023년 `train.csv` 1,221,585구
- 검증: 2024년 253,507구
- Trackman: 검증 시즌보다 이전 시즌의 기록만 사용
- 투수 ID 매칭: `확정`, `높음` 등급 696명만 사용
- 모델: LightGBM, Brier Score 조기 종료
- 최적 반복: 122회

## 결과

| 지표 | 값 |
|---|---:|
| 2024 실제 성공률 | 0.486105 |
| 예측 확률 평균 | 0.501736 |
| Brier Score | 0.248953 |
| Brier Skill Score | 341.85 |
| AUC | 0.537526 |
| Log Loss | 0.691049 |

이 결과는 코드와 전체 피처 생성 파이프라인이 정상 동작하는지 확인한 최초 기준점이다.
2024년부터 ABS가 도입되어 2019~2023년과 성공률 수준이 달라졌고, 예측 평균이 실제보다
약 0.0156 높았다. 따라서 다음 실험에서는 2024년을 포함한 시간순 OOF 확률 보정과
Trackman·ID 피처의 ablation을 우선 검토한다. 테스트 데이터가 제공되지 않아 이 실행에서는
`submission.csv`를 생성하지 않았다.
